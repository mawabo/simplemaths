## 🏗 System Architecture

The system is built with three independent parts:

1. **Backend (Node.js)**
   - Handles logic, security, and database connections.
   - Located in: `backend/`

2. **Frontend (Angular)**
   - The visual interface (Dashboard).
   - Located in: `frontend/`

3. **Database (Firebase)**
   - Stores all data securely in the cloud.

---

## 🔐 Quick Security Overview

- **Passwords:** Never stored in plain text. (Hashed with BCrypt).
- **Access:** Admin Dashboard is protected by Firebase Auth.
- **Sensitive Ops:** Editing data requires a **Master Key** that changes every hour.
- **API:** Protected by Authentication Middleware.
